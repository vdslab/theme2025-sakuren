# processing_geojson

このディレクトリには日本の区画データ（国勢調査等の GeoJSON）を前処理するスクリプトが含まれます。主に `add_area.py` によって以下の処理を実行し、処理済み GeoJSON を `data/` 配下に出力します。

**目的**:

- GeoJSON の各フィーチャーに面積プロパティを追加する
- 同一の識別子を持つ重複フィーチャのうち最大面積のもののみを残す
- 指定グループごとにポリゴンを統合（マージ）して面積を再計算する
- MultiPolygon を単一の最大ポリゴンに変換して簡素化する
- 不要なプロパティを削除して出力を軽くする

**入力**:

- `processing_geojson/data/N03-20240101.geojson`（オリジナル GeoJSON）

**出力**:

- `processing_geojson/data/N03-20240101_processed.geojson`（処理後の GeoJSON）

**主な処理の流れ（`add_area.py`）**:

- GeoJSON を読み込む。
- 各フィーチャーについて `shapely` を使ってジオメトリを生成し、ジオメトリ面積を計算して `properties["area"]` に追加する。
- 指定した不要プロパティ（スクリプト内の `remove_props`）を削除する。
- `N03_003` が `None` の場合、`N03_004` の値で埋める。
- `(N03_001, N03_003, N03_004, N03_005)` の組み合わせでグループ化し、各グループ内で最大面積のフィーチャのみを残す（重複削除）。
- `(N03_001, N03_003)` ごとにフィーチャを集め `shapely.ops.unary_union` でジオメトリをマージし、マージ後の面積を再計算して新しいフィーチャ集合を作る。
- 各フィーチャで `MultiPolygon` の場合は最大面積の `Polygon` のみを残し、その面積をプロパティにセットする。
- 最終的に不要プロパティ（`N03_004`, `N03_005`, `area` など）を削除して出力ファイルに書き出す。

**依存関係**:

- Python 3.x
- shapely

インストール例（venv を使うことを推奨）:

```bash
python -m venv .venv
source .venv/bin/activate
pip install shapely
```

（システムや環境によっては GEOS のインストールなどが必要になる場合があります。）

**実行方法**:

```bash
# 仮想環境を有効化した状態で
python processing_geojson/add_area.py
```

実行後、`processing_geojson/data/N03-20240101_processed.geojson` が更新されます。

**注意点 / 留意事項**:

- スクリプト内での面積計算は GeoJSON の座標系に依存します（経度/緯度のまま計算すると度単位の面積になり、地上面積（m^2）ではありません）。正しい地上面積が必要な場合は適切な投影（等積投影など）に変換してから面積を算出してください。
- フィーチャの結合や largest-polygon の選択は属性の一致やジオメトリ形状に大きく依存します。元データの整合性が低い場合は意図しない結合や切り捨てが発生する可能性があります。
- スクリプトはコンソールへ進捗をプリントします。大量データを扱う場合はログを制御するか一部出力を抑えると良いです。
- 出力 GeoJSON の構造（プロパティ名や削除される属性）を利用する他の処理がある場合は、それらに合わせて `add_area.py` の削除対象やフィールド処理を調整してください。
